# MyCard 应用界面设计约定

全局应用界面与银行卡图形独立。Theme.kt 的 walletColors 管理四种风格及其明暗色板；WalletDesign 管理触控尺寸、页面边距与圆角，Type.kt 管理共享 Typography。界面采用 Material 3 状态色、描边及水波反馈，不为按钮硬编码绿色。危险操作使用 error，并保留确认/撤销流程。

新装极简白；旧 theme/stacked 键只作为兼容回退，尚未选择新版选项时不重置旧偏好。新版 palette/layout 用独立键保存；选择 palette 原子写入并关闭 followSystem。跟随系统开启后优先决定明暗，所选风格保留；手动选择再次优先。UI 切换不修改 Room 卡片。

首页操作分三层：标题与数量（数量弱化为次要信息）、搜索与添加；“视图选项”菜单收纳排布方式与卡片排序；分类筛选独占一行。48dp 触控，分类水平滚动，首页只保留“添加”一个实心按钮，其余为描边或 tonal；大字体标题使用较小一级的同系字型。设置采用分组圆角 Surface；主题两列换行，长选项通过垂直下拉菜单选择，避免挤入横向长行。首页标题文案为“我的卡片”，由 `Copy.collection` 单一定义，三种排布、空卡包与搜索态共用同一处，不在各页面重复硬编码；用户自行填写的银行卡名称与卡片昵称不随标题改动。

堆叠交互继续分离“绘制占位”和“已选择”：首次点击任意未选卡展开，再次点击进详情。列表一击详情。卡册按卡片 ID 保持当前位置，数据重排仍锁定同一记录；移除/过滤当前记录时选择合法相邻位置，空结果显示原有空状态。滑动期间不把邻卡误点为详情；前后按钮在边界禁用，并显示页数与边界说明。

排列方式为堆叠卡包、完整列表、翻页卡册三种。1.2.0 的“轮播画廊”已移除：历史设置值在读取时映射到“翻页卡册”，不会崩溃也不影响其它偏好；卡册沿用原有大卡尺寸、左右滑动与前后按钮，未因移除而缩小卡片。

卡面圆角使用连续曲率近似：`ui/theme/Shapes.kt` 用超椭圆（Lamé 曲线，n=4）四分之一逐点采样生成角部，曲率在直边处连续趋于 0，不会像圆弧那样留下明显的相切缝。这是视觉近似，不是 Apple 连续圆角的同一条样条，也不是普通圆角矩形；`CardVisualTest` 用超椭圆公式、轮廓闭合与“角部区域填充量”三项断言守住这一点（同尺寸 44px 角部区域：连续角 1818px，圆弧 1556px）。`WalletDesign.cardShape` 是卡面轮廓唯一来源，裁剪、描边与阴影共用它，不会各自漂移。

边缘高光与阴影保持克制：描边不再是单一白色细线，而是沿同一轮廓、从左上加亮到右下压暗的线性渐变（`cardEdgeLight` / `cardEdgeShade`）；阴影走 `Modifier.cardShadow(elevation)`，只在需要层级时提升（堆叠中只有已选中卡、详情页大卡），浅色主题用低透明度中性阴影、深色主题加深，避免生硬黑边，也避免叠放时每张卡都建图层。

卡面文字颜色按区域判定：`ui/CardContrast.kt` 把卡面分为标题（银行名与卡类型）、标签、页脚（昵称与字标）、尾号四个区域，每区按卡面实际渐变多点采样（渐变方向 (0,0)→(1,1.3)，与绘制一致），只有在该区所有采样上都成立时才选黑或白；某行文字即使调高透明度也达不到目标时，只在标题区加一层很轻的同色衬底。目标为普通文字 ≥4.5:1、大字号 ≥3:1。`HomeEdgeCaseTest` 对 16 个模板 × 渐变开关 × 四个区域逐一断言并打印需要衬底的数量；原“整卡平均亮度”启发式已移除。

卡面以 353dp 参考宽度整体缩放，内部字型与图案比例不被系统字体单独拉散。大字号用户可通过卡片下方标题及详情字段读取完整文字；这些应用文本仍遵循字体设置。银行卡数据、原模板编号及存储颜色完全不改。

动画采用短时、低幅度过渡。graphicsLayer 只在绘制层读取 Pager 偏移，旋转始终位于前视小角度；关闭动画后取消附加视觉变换及页面过渡，原生滑动/吸附仍可用。没有定时自动轮播、无限页数或持续随机绘制。

## 设计令牌

`WalletDesign`（`ui/theme/Theme.kt`）统一卡面几何与层级：`cardRadius`(22dp)、`cardStrokeWidth`(1dp)、`cardStrokeAlpha`(0.12)、`cardEdge`、`cardShape`，以及暂未启用的 `cardElevationRest/Selected/Dragging`。`ui/CardFace.kt`、`ui/MaterialBackground.kt`、`ui/LegacyTemplateBackground.kt` 与首页堆叠裁剪共用这组值，不再各自写 22dp 与 1px 描边。

`WalletMotion`（`ui/theme/Motion.kt`）统一动效参数：`quick`(160)、`standard`(180)、`popEnter`(200)、`enter`(220)、`page`(260)、`expand`(300) 与统一缓动 `easing`（FastOutSlowInEasing，即 `tween` 原有默认值）；弹簧预设 `criticallyDamped`/`momentum` 已定义但尚未接入，留给手势与展开阶段使用，避免该阶段再引入第二套数值。

阶段 0 只做等价替换：所有令牌取值等于改动前就地写死的数值，卡片外观、导航时长与关闭动画时的静态表现均不变。已知待处理项：卡面文字色由整卡平均亮度决定（`cardInk`），浅色渐变端（模板 4/9/10）对比度约 1.65–1.86:1，属后续排版与对比度任务范围，本轮不修改卡面配色。
