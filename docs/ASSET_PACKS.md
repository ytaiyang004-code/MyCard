# 本地素材库扩展约定

当前 `ui/Copy.kt` 中的 `TemplateCatalog` 提供六个稳定模板 ID、中文名称、默认主辅色、颜色选项；`CardFace.kt` 是渲染入口。卡片同时保存 template 和 imagePath，切换模式不丢失另一种模式的设置。

第一版不打包任何真实银行图片。原生 Canvas 模板不依赖外部授权素材，用户可逐张导入自己有权使用的图片。

后续素材包应作为独立导入模块实现，不直接把外部包里的路径写入数据库。建议：

- 版本化清单，素材 ID、名称、发行方描述、图片文件名、授权说明和标准比例信息。
- 仅允许 PNG / JPEG / WebP；验证文件大小、展开后总大小和数量，防止路径遍历及压缩炸弹。
- 每张图片仍经过现有本地解码、比例处理、脱敏确认和重新编码流程，再分配新的内部 UUID。
- 素材目录只负责查找和描述；用户记录引用内部图片 ID，不能依赖外部包绝对路径。
- 模板 ID 1.0 中为 0–5。新增模板时同步更新校验、渲染、备份兼容策略及测试，不改变既有 ID 含义。

**批量素材包导入界面尚未实现，也没有展示占位入口。** 这份约定用于后续离线扩展。
