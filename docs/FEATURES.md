## 仍需验收或未纳入第一版

- 本次公开版本未做真机验收；系统图片选择器、真实 Keystore、生物识别、截图 / 录屏和窗口恢复、进程被系统杀死后的重开、拖动手感及长列表帧率需要真机确认。
- 图片处理是固定比例裁剪，不含拍摄透视的四角矫正、OCR 或自动识别卡号。没有自动抓图或在线素材搜索。
- 预置素材库是可扩展的本地 TemplateCatalog；尚无“批量离线素材包导入器”。第一版可逐张导入本地图片，后续素材包设计见 ASSET_PACKS.md。
- 草稿及尚未保存的裁剪结果只在内存中保留，进程被系统结束后会丢失；已经保存的卡片不受影响。
- 备份上限 5,000 张 / 256 MiB，输入图片 24 MiB 上限；不支持无限尺寸图片与无限大备份。
- 本地加密采用记录级认证加密，不是 SQLCipher 全库加密；数据库结构、随机 ID 和记录数量仍可从文件结构观察到。全部用户字段与卡面均加密。
- Debug 包用于个人测试。仓库不提供正式发布签名，也没有进行第三方安全审计。
