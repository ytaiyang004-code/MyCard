# 数据保护设计

## 本地数据

Room 表仅保存随机 UUID 主键和二进制加密 payload。银行名称、卡组织、类型、后四位、昵称、标签、备注、图片相对路径、模板配置、置顶 / 归档、排序和时间均在 payload 内。每条记录使用 Android Keystore 生成的 AES-256 密钥进行 AES/GCM/NoPadding 加密，随机 96-bit nonce、128-bit tag，记录 ID 作为 AAD 绑定身份，防止交换记录密文。

图片仅在裁剪、遮挡、重新编码后写入 `noBackupFilesDir/card_art`；每张图片另行 AES-GCM 加密，文件名使用随机 UUID，AAD 绑定文件名。Coil 只接收解密后的内存数据，磁盘与内存图片缓存均禁用。未引入 Coil 网络模块。

DataStore 只保存主题、布局、尾号默认显示、排序、动画、隐私锁设置；旧版最近任务保护键已忽略，不保存银行卡信息或备份密码。

这不是全库 SQLCipher 加密：SQLite 的结构、随机 ID、条数等非用户内容元数据仍可观察到。首次版本不需要数据库版本迁移，已导出 v1 schema；后续变更应新增 Migration，禁止 destructive migration 自动清空。

## 图片流程

系统选择 URI → 限长内存读取 → ImageDecoder 软件解码（处理方向）→ 限最长边 → 固定比例裁剪 → 在新 Bitmap 上绘制全不透明黑色遮挡 → PNG 重新编码 → 加密保存。

原始未脱敏图片不写入应用文件、缓存或数据库。失败或取消会释放内存引用；输入字节缓冲使用完毕清零。原图仍留在用户原来的相册 / 文件位置，MyCard 不会删除它。使用新 Bitmap 编码，不复制原 EXIF、定位或相机信息。遮挡后不保存任何用于还原敏感像素的图层或原始副本。

预览和遮挡导出使用同一裁剪几何函数。有遮挡时锁定平移 / 缩放，避免调整图片后遮挡错位。要重新裁剪，先清除尚未保存的遮挡。图片处理对话框也允许正常截图和录屏。

图像保存失败会回收不再引用的加密文件；删除撤销窗口结束后清理相应图片；进程异常结束留下的未引用加密文件在下次启动清理。不会因清理操作移除仍有记录引用的图片。

## 隐私锁

BiometricPrompt 使用系统支持的生物识别或设备凭据。启用 / 关闭均需认证，离开应用触发锁定。验证失败或取消不会进入卡包。

这是应用访问锁，不将生物特征作为跨设备密钥，也不声称阻止已取得 root、调试执行权或操作系统控制权的攻击者。设备密钥不要求每条记录解密都弹出生物识别；密钥由 Keystore 持有，UI 统一控制访问。1.0.1 已移除所有应用级防截图标志及相关设置；允许截图、录屏和投屏。锁定时保留导航状态，暂时隐藏页面弹窗并显示可认证的锁屏窗口。

Android 云备份、设备转移均在 Manifest 和两套 extraction / backup XML 中关闭。未申请 INTERNET、NFC、相机或全量相册权限。没有遥测、广告、追踪与云服务。复制功能仅复制后四位，并标记系统敏感剪贴板。

## 可移植备份 v2

备份口令由用户设置，8–128 字符；不持久化。标准 JCA PBKDF2WithHmacSHA256 使用 600,000 次迭代、16-byte 随机盐派生 256-bit AES 密钥。备份不依赖设备 Keystore 密钥，可在其他安装上使用相同密码恢复。1.1.0 的内部 JSON 清单为 v2，恢复兼容旧 v1；外层 MYCARD02 加密格式不变，旧应用会拒绝 v2 清单，避免静默忽略新增设计字段。

外层二进制格式：

1. 8-byte magic `MYCARD02`、4-byte 固定迭代次数、16-byte 随机盐。
2. 每个数据块先写 4-byte 大端长度，然后写 `nonce(12) || AES-GCM ciphertext || tag(16)`。明文块最大 64 KiB。
3. 每块 AAD 为完整头部和递增的 4-byte 块序号。每块使用独立随机 nonce。
4. 最后必须有一个认证的空块作为结束标记，且文件不得有任何尾随字节。缺失、换序、修改或截断块均不能作为完整备份恢复。

内层为有长度上限的 JSON 清单和逐个有长度上限的 PNG 数据。最多 5,000 条记录、256 MiB 明文。恢复时只处理单个图片和小块，不解密整个文件到内存或明文临时文件。

恢复分阶段验证密码、字段、唯一 ID、图片引用、长度、PNG 尺寸和末尾认证标记，先为图片生成新的随机文件名并加密写入，最后在 Room 事务里合并记录。若失败，现有卡片不改动，清理新建且未引用的加密文件；最后提交和失败清理保护协程取消边界。

新增版本不能静默更改当前格式；未知 magic / 格式版本必须拒绝。没有导出任何曾对用户交付的 v1 备份，本次正式交付从 v2 格式开始。

## 边界

- 忘记备份密码无法找回。卸载应用会移除私有数据及设备密钥，迁移前应导出密码备份。
- 文件删除不能对闪存磨损均衡提供物理安全擦除保证；应用依赖私有空间、文件加密和 Keystore。
- Debug 允许调试，只适合用户明确需要的个人测试场景；正式分发应使用自己的 Release 签名。
- 软件运行环境已测试标准加密、错误密码、篡改、截断和数据库 / 图片流程。硬件 Keystore、具体厂商生物识别仍待真机验证。
